# SoloArtisan — Design System (Week 02)

This document defines the design direction, styling tokens, and visual evidence for the SoloArtisan project.  
It is part of the planning phase required for Week 02.

---

## 1. Color Schema

The visual style aims for a warm, handcrafted aesthetic with natural tones.  
The palette used is the following:

- **Primary**: `#7A4F2B` — Warm chestnut brown  
- **Secondary**: `#F5E9DE` — Soft cream  
- **Accent**: `#A3C4BC` — Muted sage green  
- **Neutral Dark**: `#222222` — Base text color  
- **Neutral Light**: `#F7F7F7` — Light UI background  

Palette image:  
`/design/palette.png`

---

## 2. Typography

The chosen fonts are clean, modern and easy to read, matching the warm artisan brand.

### **Headings (H1–H6)**  
- **Font**: Inter, sans-serif  
- **Weights**: 600–800  
- **Sizing scale**:  
  - H1: 48px  
  - H2: 34px  
  - H3: 24px  
  - H4: 20px  
  - Body: 16px  

### **Body Text**
- **Font**: Roboto or System UI Sans  
- **Weight**: 400  
- **Line height**: 1.5–1.7

---

## 3. Spacing System

Consistent spacing improves usability and visual rhythm.

- Base unit: **4px**
- Multipliers used:  
  - 4px — 8px — 12px — 16px — 20px — 24px — 32px — 40px — 48px  

Recommended usage:
- Sections: 40–48px top/bottom  
- Cards: 20–24px padding  
- Form fields: 12–16px padding  

---

## 4. Components (Initial Planning)

### **Header**
- Sticky top navigation  
- Mobile hamburger menu  
- Logo left, navigation center, actions right  

### **Product Card**
- Large photo  
- Title  
- Price  
- “Add to cart” button  
- Subtle hover elevation  

### **Buttons**
- Primary button: chestnut brown background, cream text  
- Secondary button: outline, sage accent  

---

## 5. Accessibility Notes

- Minimum contrast ratio: **4.5:1**  
- All images must have descriptive alt text  
- Keyboard navigation fully supported  
- Focus-visible must be visible and consistent
